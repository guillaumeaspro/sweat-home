# Sweat Home

Ton coach sportif à la maison : un programme selon ta forme, ton temps et ton matériel, avec chrono, démonstrations en vidéo et mannequin 3D.

L'appli s'installe sur l'écran d'accueil du téléphone et fonctionne hors connexion une fois ouverte. Les données restent dans le navigateur de chaque personne.
